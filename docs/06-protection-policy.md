# 6. Intune 앱 보호 정책 구성

### 4.8 Intune 앱 보호 정책 구성

#### 정책 생성

```
Intune 관리 센터 > 앱 > 앱 관리 > 보호 > 만들기 > iOS/iPadOS
```

| 단계 | 설정 |
|---|---|
| 1. 기본 | 정책명 지정 |
| 2. 앱 | 정책 대상 → 선택한 앱 → 사용자 지정 앱에 `org.example.wraptestb` 등록 |
| 3. 데이터 보호 | 화면 캡처 차단, 다른 앱으로 데이터 전송 제한, 잘라내기/복사/붙여넣기 제한 |
| 4. 액세스 요구 사항 | PIN 필수, 최소 길이 4, 생체 인식 허용 |
| 5. 조건부 시작 | 기본값 (PIN 재시도 5회, 탈옥 기기 차단) |
| 6. 할당 | 대상 그룹 지정 |
| 7. 검토 + 만들기 | 배포 |

**Store에 등록되지 않은 커스텀 앱은 "공개 앱"이 아닌 "사용자 지정 앱"으로 Bundle ID를 직접 입력**해야 합니다.

#### 정책 적용 확인

```
Intune > 문제 해결 및 지원 > 사용자 검색
```

```
사용자 상태: 사용하는 계정 ✅ / Intune 사용이 허가됨 ✅
앱 보호: 체크인 1 / 체크인되지 않음 1
```

앱이 Intune 서비스에 체크인을 시도한 기록이 남아, MAM SDK가 실제로 서버와 통신하고 있음을 확인했습니다.
